## 들어가며

OpenAI가 2026년 7월 30일 GPT-5.6 Luna의 API 가격을 80%, Terra는 20% 내렸어요. Luna는 100만 토큰당 입력 1달러, 출력 6달러에서 입력 0.20달러, 출력 1.20달러가 됐습니다. 출시 후 약 3주 만의 가격 인하입니다.

이번 변화는 API 비용뿐 아니라 ChatGPT Work와 Codex의 유료 구독 사용량에도 반영됩니다. 최근 대기업에서도 프론티어 모델을 엔터프라이즈 환경에 도입하기 시작했지만, 높은 비용 때문에 구성원에게 충분한 할당량을 주기 어렵다는 이야기가 있어요. 이번 변화가 이런 압박을 얼마나 줄여 줄지 궁금합니다.

---

## 유료 구독에서도 Luna와 Terra를 더 많이 쓸 수 있습니다

[OpenAI 공식 발표](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/)에 따르면 ChatGPT와 Codex의 구독 가격과 할당량 예산은 그대로입니다. 대신 Luna와 Terra를 사용할 때 차감되는 크레딧이 줄어요.

OpenAI에서 Codex와 ChatGPT를 담당하는 [Tibo도 X에서](https://x.com/thsottiaux/status/2082883808194707792) API 가격과 유료 구독의 사용량 모두에 적용된다고 설명했습니다. 월 구독료가 내려가는 것은 아니지만, 같은 구독 안에서 Luna와 Terra로 실행할 수 있는 작업은 늘어납니다.

Sol 가격은 그대로라서 최고급 모델만 계속 사용한다면 직접적인 변화는 크지 않아요. 다만 일상적인 분류와 문서 정리, 기준이 분명한 반복 작업을 Luna로 옮기면 중요한 판단에 쓸 사용량을 남길 수 있습니다.

---

## 가격표보다 실제 업무 벤치마크가 필요합니다

집에서 앱 알림 가운데 광고를 제외하고 필요한 알림만 골라내는 기능을 시험한 적이 있어요. 당시 몇 가지 모델을 비교한 뒤 GPT-5.4 mini를 선택했던 것으로 기억합니다.

[현재 API 가격표](https://developers.openai.com/api/docs/pricing)에서 GPT-5.4 mini는 입력 0.75달러, 출력 4.50달러입니다. Luna는 입력 0.20달러, 출력 1.20달러이므로 같은 양의 토큰을 사용한다면 약 73% 저렴해요.

교체 여부는 같은 데이터로 다시 확인해야 합니다. 광고를 제대로 제외하는지, 필요한 배달 알림을 놓치지 않는지, 응답 속도와 재시도까지 포함한 비용이 어떤지를 봐야 해요. 세대 비교 대상으로 생각할 수 있는 GPT-5.5 mini는 현재 공식 API 모델 목록과 가격표에서 확인되지 않아 달러 단가를 비교하지 않았습니다.

결국 모델 가격이 내려갈수록 벤치마크가 더 중요해집니다. 저렴한 모델이 자주 실패하면 재시도와 사람의 검토 비용이 늘어날 수 있기 때문이에요.

## Agent의 반복 비용이 내려갑니다

Agent는 한 번 답하고 끝나지 않습니다. 계획을 세우고, 도구를 실행하고, 결과를 확인한 뒤 문제가 있으면 다시 시도합니다. 한 번의 요청 안에서도 모델을 여러 차례 호출하므로 토큰 단가는 실행 가능한 반복 횟수와 연결돼요.

OpenAI도 불확실한 문제와 계획 수립은 Sol이 맡고, 요구 사항이 분명한 변경과 테스트·평가는 Luna가 맡는 방식을 예로 들었습니다. 모든 작업에 가장 강한 모델을 쓰기보다, 실제 벤치마크를 통과한 업무부터 저렴한 모델로 옮기는 방식입니다.

---

## PCB·PKG 설계 Agent에도 같은 기준이 필요합니다

PCB·PKG 설계에서도 설계 목표를 해석하고 예외를 판단하는 일은 사람이나 강한 모델이 맡을 수 있어요. 설계 데이터 정리, 도구 실행, DRC 결과 분류, 정해진 조건의 해석 반복은 Luna 같은 모델의 후보가 됩니다.

다만 여기서도 가격표만으로 결정할 수는 없습니다. 실제 설계 과제에서 필요한 도구를 제대로 선택하는지, DRC와 해석 결과를 정확하게 읽는지, 실패 뒤 조건을 바꿔 다시 실행할 수 있는지를 평가해야 합니다.

---

## 마무리

Luna의 80% 가격 인하는 대량의 반복 업무에 AI를 적용할 수 있는 범위를 넓혔습니다. 유료 구독에서도 크레딧 차감이 줄어들어 기업의 할당량 압박을 낮추는 데도 어느 정도 도움이 될 것 같아요.

Sol을 포함한 최고급 모델의 비용이 모두 내려간 것은 아닙니다. 결국 조직이 해야 할 일은 업무별 품질 기준을 만들고, 그 기준을 통과한 작업부터 Luna와 Terra로 옮기는 것입니다. 같은 비용으로 더 많은 Agent를 실행할 수 있게 된 만큼, 모델을 고르는 벤치마크와 결과를 확인하는 검증 체계가 더 중요해질 것 같습니다.
