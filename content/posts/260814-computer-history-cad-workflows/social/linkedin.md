OpenAI가 ChatGPT와 Codex가 컴퓨터에서 한 일을 기억하는 Computer History를 공개했습니다.

최근 작업을 이어서 진행하고, 반복되는 흐름을 발견하면 Skill이나 자동화 후보를 제안하는 기능입니다.

이 기능을 보며 CAD 사용자의 작업 기록도 설계 자동화의 중요한 입력이 될 수 있겠다는 생각이 들었어요.

CAD 설계에는 객체 생성과 배치, 연결, 속성과 제약 조건 변경, 검토처럼 종류가 다른 작업이 이어집니다. 그래서 click과 shortcut만 기록해서는 부족합니다. 어떤 설계 객체를 다뤘고, 어떤 command를 실행했으며, 설계 상태가 어떻게 바뀌었는지도 함께 남아야 합니다.

이런 기록이 쌓이면 AI가 반복되는 작업 순서를 찾아 macro, script, Skill이나 Agent workflow의 후보를 제안할 수 있을 것 같아요.

물론 반복한 작업이 항상 좋은 절차인 것은 아닙니다. AI가 찾은 후보는 다시 검토하고 검증해야 하고, 설계 IP와 고객 정보에 대한 접근 권한도 필요합니다.

사람이 자동화 절차를 처음부터 모두 설명하는 대신, AI가 실제 작업에서 자동화할 부분을 함께 찾아내는 방식입니다.
