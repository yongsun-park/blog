# 본문 1/2

OpenAI가 Computer History를 공개했음.

ChatGPT와 Codex가 컴퓨터에서 한 일을 기억하고, 반복되는 흐름을 발견하면 Skill이나 자동화 후보를 제안하는 기능임.

이걸 보면서 CAD 사용자의 작업 기록도 설계 자동화의 중요한 입력이 될 수 있겠다는 생각이 들었음.

# 연결 글 2/2

다만 CAD는 click과 shortcut만 기록해서는 부족함.

어떤 설계 객체를 다뤘는지, 어떤 command를 실행했는지, 설계 상태가 어떻게 바뀌었는지가 함께 남아야 함.

이런 기록이 쌓이면 AI가 반복되는 작업 순서를 찾아 macro, script, Skill이나 Agent workflow의 후보를 먼저 제안할 수도 있을 듯.

물론 반복한 작업이 항상 좋은 절차인 건 아님. 사람이 다시 검토하고 검증해야 함.
